Technical Stack and Tools

The Meat Point Astana website was built as a collaborative university project by a team of three students. We focused strictly on semantic HTML5 without using Cascading Style Sheets (CSS) or JavaScript (JS). As stated in Web Standards Guide, Clean structure precedes layout. This approach ensures our code remains lightweight and natively accessible for screen readers.

During development, we utilized Git for version control. To run the local development server on port 8000, you can type python -m http.server in your terminal interface. All our markup uses standard UTF-8 encoding and pure H2O logical structures.

Code Examples and Validation

A common block of code across all pages is the navigation bar. Below is a raw code snippet:


<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
    </ul>
</nav>

We tested all pages using the W3C Validator to guarantee 0 errors. A typical error output during testing looked like this: Error: Stray end tag nav. We also used entities like &lt;, &gt;, &amp;, and © throughout the project.

Our Development Experience

Building this restaurant platform taught us how to collaborate effectively using Git branches and daily commits. Resolving merge conflicts was a practical challenge. By sticking strictly to semantic elements, Madiyar Akylbek and the Meat Point team learned how browsers render raw markup natively. Working in a team of three required clear communication to divide the eight pages and satisfy all checklist items.
