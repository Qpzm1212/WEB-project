Technical Stack and Tools

The Meat Point Astana website was built as a collaborative university project by a team of three students. We focused strictly on semantic HTML without the use of Cascading Style Sheets (CSS) or JavaScript (JS).

During the development process, we utilized Git for version control. When running the local development environment or checking files, you might need to use specific terminal commands. For example, to test the project locally, you would typically type python -m http.server or npm start in your command-line interface.

Development Milestones

  1. Final Quality Assurance and deployment.
  2. Form implementation and cross-page testing.
  3. Semantic markup of all written content.
  4. Initial GitHub repository setup.

Code Examples and Validation

Throughout the project, we used standard HTML5 tags. A common block of code used across all pages is the main navigation structure. Here is a raw example of how we implemented the semantic navigation markup: 


<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
    </ul>
</nav>

We rigorously tested our pages using the W3C Validator to achieve zero errors. Catching these errors early helped us maintain high code quality.

Our Development Experience

Building this restaurant website taught us how to collaborate effectively using Git branches and commits. Resolving merge conflicts and ensuring everyone made their required commits on different days was a practical challenge.
